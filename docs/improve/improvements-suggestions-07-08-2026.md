| I1 | Security | 🟣 Blocker | Secrets whitelisted for npm publish | `package.json:62-92` `files` array is a publish **allowlist** that explicitly names `.env.production`, `.env.test`, and `token.json`. The package is `"private": false` (`package.json:4`) with a public `homepage`. `npm publish` uploads every listed path that exists at publish time — so a publish run performed after the app has been used would push the OAuth **refresh token** (`token.json`) and the Google **client secret** (`.env.production`) to the public npm registry. `.gitignore` protects git but does **not** protect `npm publish` when a `files` allowlist names the file explicitly. There is no `.npmignore` fallback. |
